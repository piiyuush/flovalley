# 🌸 Flovalley — Handcrafted Velvet Pipe Cleaner Flora

Flovalley is a boutique showcase and ordering website for bespoke, everlasting pipe cleaner flowers. Designed for fast mobile browsing, instant code copying, and direct ordering via Instagram DM and WhatsApp.

---

## 🛠️ Tech Stack & Hosting
- **Hosting:** 100% Free on GitHub Pages
- **Styling:** Tailwind CSS + Google Fonts (Playfair Display & Plus Jakarta Sans)
- **CMS / Database:** Google Sheets (Live dynamic CSV sync)
